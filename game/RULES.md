# 지식전쟁 (가제) — 룰북 v0.1

> 학교 과제 제출 양식(게임 개요 → 프롤로그 → 학습 목표 → 학습 요소 → 게임 규칙 → 점수 계산 → 게임 이미지)에 맞춰 정리한 초안입니다.
> 이 문서는 `game/data/characters.json`, `game/data/cards.json`(260장)과 함께 사용합니다.

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | 지식전쟁 (가제) |
| 대상 / 인원 | 중·고등학생, 4인 기준 (3~5인까지 확장 가능) |
| 소요시간 | 30~45분 (서든데스 포함 시 최대 60분) |
| 목표 | 6개 교과 진영 중 배정된 진영의 캐릭터로 마지막까지 생존하기 |
| 연결 과목 | 수학, 영어, 국어, 통합사회, 통합과학, 한국사 (복수 융합) |
| 메커니즘 | 순차 진행형 카드 배틀(갓필드 방식) + 진영-과목 일치 보너스 + 노출 학습형 카드 텍스트 |

## 2. 프롤로그 (세계관 / 이론적 배경)

AI가 계산·번역·정보 검색을 인간보다 능숙하게 해내기 시작하면서, 인간 세계에는 "이걸 굳이 배워야 하나?"라는 질문이 늘어난다.

지식의 세계에 사는 개념들—파이, 훈민정음, 은유법, 관성—은 이 변화를 실시간으로 체감한다. 인간의 관심이 줄어들수록 그들의 힘도 약해지기 때문이다. 모든 지식을 다 유지할 수 없다는 위기감 속에서, 각 개념은 스스로가 **"AI로 대체될 수 없는 존재"**임을 증명해야 살아남는다.

정보(+AI) 진영은 위협의 근원이기에 플레이 가능한 진영에서 제외되고, 배경 세력으로만 존재한다. 체육·유도·진로는 애초에 독립 진영이 아니라, 어느 진영이든 쓸 수 있는 **공용 카드**로 세계관에 녹아 있다.

다 함께 살아남을 수 없다는 절박함 속에서, 결국 개념들은 서로 경쟁하게 된다 — 이것이 이 게임의 전투다.

---

## 3. 학습 목표

1. 6개 교과의 핵심 개념을 카드/캐릭터를 통해 반복적으로 접하며 **노출 학습** 효과를 얻는다.
2. 서로 다른 교과 개념이 하나의 규칙 체계(전투) 안에서 상호작용하는 것을 보며 **교과 간 연결성**을 체감한다.
3. 카드 텍스트(개념 설명)를 읽고 활용하는 과정에서 **자기주도적 개념 확인** 습관을 기른다.
4. 진영 배정이 매판 랜덤이기 때문에, 원치 않는 과목이라도 최소 1회 이상 접하게 되어 **학습 편식을 줄인다.**

## 4. 학습 요소 (2022 개정 교육과정 6대 핵심역량 연계)

| 핵심역량 | 게임 내 반영 요소 |
|---|---|
| 지식정보처리 역량 | 카드 하단 개념 설명을 실시간으로 읽고 판단에 활용 |
| 창의적 사고 역량 | 진영-과목 불일치 상황에서 카드 조합을 창의적으로 구성 |
| 심미적 감성 역량 | 국어 진영의 수사법 카드, 캐릭터 세계관·비주얼 |
| 의사소통 역량 | 턴마다 타겟 선언, 방어 여부 협상(자유 타겟팅) |
| 협업적 소통 역량 | 시그마·삼일운동 등 "같은 진영 카드 연계" 특수능력 |
| 공동체 역량 | 매판 진영이 랜덤 배정되므로, 특정 과목에 대한 고정관념 없이 참여 |

## 5. 준비물

- 캐릭터 스탠드 6종(진영별 1틀, 유희왕 듀얼디스크 방식 카드 인터페이스)
- 캐릭터 카드/토큰 24종 (진영당 4명, `game/data/characters.json` 참고)
- 공용 카드 풀 260장 (`game/data/cards.json`, `cards.csv`)
- HP/MP 트래커: 하트·별 슬롯 + 토큰
- 최대치 봉인 캡(검은색 벙커형, 진영 공용 규격)
- 4면 주사위 또는 가위바위보(진영 랜덤 배정용)
- 라운드 카운터(서든데스 판정용)

## 6. 게임 규칙

### 6.1 준비 단계

1. 6개 진영(수학/영어/국어/통합사회/통합과학/한국사) 중 참가 인원수만큼 **가위바위보 등 무작위 방식**으로 진영을 배정한다. 진영당 1명만 참전한다.
2. 각 플레이어는 배정된 진영 안에서 캐릭터 1명을 **자유 선택**한다.
3. 캐릭터의 초기 HP/MP를 `characters.json` 값대로 세팅한다.
4. 공용 카드 풀(260장)을 셔플해 각 플레이어에게 시작 손패 5장을 나눠준다(진영 과목 카드 위주로 구성해도 무방).
5. 라운드 카운터를 0으로 둔다.

### 6.2 턴 구조

한 라운드는 참가자 전원이 한 번씩 행동하는 것으로 구성된다. 턴 순서는 시계 방향.

1. **① 순차 진행** — 정해진 순서대로 한 명씩 턴을 진행한다(동시 행동 없음).
2. **② 자유 타겟팅** — 자기 턴의 플레이어는 생존한 상대 중 누구든 자유롭게 공격 대상으로 지정할 수 있다.
3. **③ 카드 사용** — 손패에서 카드 1장(공격/방어/유틸 중 1)을 내고 MP를 지불한다. 캐릭터 특수능력은 조건 충족 시 별도로 발동 가능.
4. **④ 방어 선언(강제 아님)** — 공격을 받은 플레이어는 방어 카드를 낼지 여부를 선택한다. 내지 않으면 데미지를 그대로 받는다.
5. **⑤ 카드 없음 → 패스** — 낼 수 있는 카드가 없거나 MP가 부족하면 턴을 패스한다. 패스해도 라운드는 진행된다.
6. 전원 턴이 끝나면 한 라운드 종료, 카운터 +1. 각 플레이어는 손패를 1장 보충한다(최대 손패 6장).

### 6.3 진영-과목 일치 보너스

- 캐릭터 소속 진영과 사용한 카드의 과목(subject)이 같으면:
  - MP 소모 **-1** (최소 1)
  - 카드 효과(데미지/방어/유틸 보정치) **+20%**
- **공용 카드**(체육/진로)는 모든 진영에서 보너스 없이 정가로 사용 가능하다.

### 6.4 승리 조건

- HP가 0 이하가 된 캐릭터는 탈락한다.
- 마지막까지 생존한 1명(또는 팀전일 경우 1개 팀)이 승리한다.
- 동시에 전멸하는 경우, **남은 MP 합 → 그래도 동률이면 이번 게임에서 사용한 총 데미지 합**이 높은 쪽이 승리한다.

### 6.5 서든데스 규칙

- **발동 조건**: 라운드 카운터가 **15**를 초과하는 순간 서든데스에 돌입한다.
- **효과**:
  1. 모든 생존 캐릭터의 HP를 즉시 50%로 조정(반올림).
  2. 이후 매 라운드 종료 시 전원 HP -10%(고정 비율, 반올림).
  3. 방어 카드 사용 불가 — 서든데스 중에는 공격/유틸 카드만 낼 수 있다.
  4. 캐릭터 특수능력 쿨다운을 전부 초기화(1회 재사용 가능).
- 서든데스는 "게임이 무한정 길어지는 것"을 막기 위한 장치이며, 위 수치는 플레이테스트 후 조정 예정(캐릭터 밸런스 확정 뒤 최종 확정).

## 7. 점수 계산

### 7.1 게임 내 승점 (라운드 결과용)

| 순위 | 점수 |
|---|---|
| 1위(최종 생존) | 4점 |
| 2위(두 번째 탈락자) | 2점 |
| 3위 | 1점 |
| 4위(최초 탈락자) | 0점 |

- 여러 판을 이어서 진행할 경우 누적 승점으로 최종 우승자를 가린다.
- 보조 지표(선택): 이번 판에서 **자기 진영-과목 일치 카드**를 몇 번 사용했는지 기록해 "개념 활용 지수"로 별도 집계 가능(학습효과 측정용 확장 규칙).

### 7.2 학습효과 측정(과제용 선택 지표)

수업/평가 맥락에서 활용할 경우, 아래를 관찰 체크리스트로 사용할 수 있다.

- 카드 하단 설명을 소리 내어 읽거나 언급한 횟수
- 진영-과목 일치 보너스를 스스로 계산해 활용한 횟수
- 게임 종료 후 간단한 개념 회상 퀴즈 정답률(디지털화 확장 시 자동 채점 가능)

---

## 8. 확장 옵션 (디지털화, 심화)

- 카드 텍스트/판정을 자동화한 웹·앱 버전으로 확장 가능 (`game/data/cards.json`이 그대로 데이터 소스가 됨).
- 정보(+AI) 진영을 "이벤트 카드"로 부활시켜, 특정 라운드마다 전원에게 랜덤 페널티/버프를 주는 시스템(선택 룰)으로 세계관을 강화할 수 있다.
- 성장/해금 시스템은 기본 룰에서 배제하되, 확장판에서는 "판마다 갱신되는 임시 특성" 형태로만 흡수한다(무게감 최소화 원칙 유지).
