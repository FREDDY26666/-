# 지식전쟁 (가제) — 게임 데이터 & 룰북

교과 개념을 카드 배틀 메커니즘 위에 얹은 게이미피케이션 보드게임 프로젝트입니다.

## 폴더 구조

```
game/
├── RULES.md          # 전체 룰북 (게임 개요/세계관/학습목표/규칙/점수계산)
├── CHARACTERS.md      # 24명 캐릭터 명단 요약
├── CARDS.md           # 260장 카드 풀 요약 + 샘플
└── data/
    ├── characters.json    # 캐릭터 원본 데이터 (진영 6 x 4명)
    ├── generate_cards.js  # 카드 풀 생성 스크립트 (node generate_cards.js)
    ├── cards.json          # 생성된 카드 260장 (기계 판독용)
    └── cards.csv            # 카드 260장 (엑셀/시트 인쇄용)
```

## 한눈에 보기

- **진영 6개**: 수학 / 영어 / 국어 / 통합사회 / 통합과학 / 한국사 (정보+AI는 배경 세력)
- **캐릭터 24명**: 진영당 4명, HP/MP + 특수능력 1개씩
- **카드 260장**: 진영별 40장(공격20/방어10/유틸10) + 공용 20장(체육10/진로10)
- **핵심 메커니즘**: 순차 진행 · 자유 타겟팅 · 강제 아닌 방어 · 진영-과목 일치 보너스(MP -1, 효과 +20%) · 서든데스(15라운드 초과 시 발동)

자세한 내용은 [`RULES.md`](./RULES.md)를 확인하세요.

## 카드 데이터 재생성

카드 밸런스나 개념 목록을 수정하려면 `data/generate_cards.js`의 `BANKS`(진영별 개념 뱅크) 또는 `RARITY_TABLE`(희귀도별 수치)을 편집한 뒤 다시 실행합니다.

```bash
cd game/data
node generate_cards.js
```
